# 架构与数据格式

## 通信与权限

Tauri 启动内嵌 Rust 服务，仅绑定 `127.0.0.1:47831`。客户端通过受限 IPC `connection` 获取本进程的桌面令牌；该令牌不通过健康检查或浏览器页面公开。

浏览器使用六位短期配对码申请独立随机令牌。配对令牌只允许状态检查、资源上传和新建收藏，不能读取资料库、WebDAV 设置或其他浏览器的令牌。令牌保存在扩展的私有本地存储中；客户端可撤销令牌。

HTTP 层同时检查 Host、Origin 和 Bearer。允许应用来源、本地开发页面及浏览器扩展来源；拒绝普通网站来源和 `null`。CORS 不作为唯一授权机制。配对、健康检查不要求令牌，但也经过来源检查。其他本地用户级进程属于应用所在操作系统账户的信任边界。

## 捕获管线

1. 扩展确认客户端在线，持久进度页获得来源标签页 ID。
2. `scripting.executeScript` 在隔离世界中执行打包的捕获引擎。
3. 整页或选区逐节点读取计算样式；伪元素转换为显式节点，已加载字体声明合并到快照。
4. X 在滚动前立即序列化已发现帖子，使用永久链接去重；Reddit 只读取已加载内容，避免重复输出嵌套评论。
5. 单独保留未添加计算样式的选区/讨论源码和页面资源引用。选区模式的正文源码仅包含选中区域，不把未选中的正文整个复制进去；head 中的原始脚本和状态仍属于源码归档。
6. 扩展下载资源，提取 CSS 的 import/url 和可静态识别的 ESM 引用。资源按 SHA-256 命名，逐个上传；超过累计 500 MiB 时等待用户选择。
7. 将快照中的成功资源引用改为相对路径，POST 收藏元数据。服务端确认依赖资源存在后写入归档并提交 revision。

单次捕获最多处理 2000 个资源；单个序列化根限制 60000 个元素，以便异常页面能明确失败。下载失败会写入资源记录，其他资源继续处理。取消不会创建收藏，已传但尚未使用的 blob 可能留在本地，当前未实现自动垃圾回收。

资源下载保存原始 CSS/JS 字节；不重写源码模块中的所有动态运行时路径，因此源码归档用于检查和备份，不承诺成为可独立运行的应用副本。

## 数据布局

```text
应用数据目录/
  library.sqlite3
  webdav.json
  blobs/<sha256>.<ext>
  archives/<uuid>/
    snapshot.html
    source.html
    posts.json
    manifest.json
    assets/<sha256>.<ext>
  events/<timestamp>--<uuid>.json
```

`blobs/` 接收经过摘要校验的资源。归档内资源优先采用硬链接，不支持时复制。SQLite 使用 WAL；事件文件是可重放的持久元数据来源，应用启动时重建/更新索引。归档文件写入完成之后才提交收藏事件。

收藏字段包括 `version`、`id`、`title`、`url`、`platform`、`mode`、`capturedAt`、`modifiedAt`、`text`、`folderId`、`tags`、`posts`、`resources`、`warnings` 和 `scope`。资源字段包括 URL、状态、MIME、字节数、摘要文件名和失败原因。

查询的至少三个 Unicode 字符使用 FTS5 trigram；更短查询使用当前文档字段的子串匹配，以支持中文单字和短词。

## WebDAV

远端与本地保持 `archives/` 和 `events/` 结构。客户端通过 PROPFIND Depth 1 列出事件；从不枚举或修改用户目录中其他内容。上传使用条件创建和不可变路径；资源与 HTML 先于事件上传，事件充当提交标志。

新设备下载归档后才导入事件。资源按文件名中 SHA-256 校验。收到的 UUID、资源名和事件名都经过校验，不能作为任意路径。重定向不自动跟随，防止将认证头转交到别处。

每个事件记录一个完整文档版本。以时间戳和随机 UUID 组成 revision，选择字典序最大的版本构建当前视图；不同设备的并发事件均保留，不使用覆盖式远端清单。删除产生墓碑。文件夹也是独立文档，通过 parentId 形成树；本地创建与移动拒绝循环。

已上传状态按服务器目录和用户名隔离，切换端点后会重新上传。本地修改、启动和一分钟周期均触发同步；同时只运行一次，失败保留本地数据并在 UI 报告。下载中的文件使用临时路径，失败时不导入索引。

## 阅读隔离

读取快照后先在 `<template>` 的惰性文档片段中清理，而不是在父文档创建可联网的元素。删除脚本、事件属性、嵌入框架、外部 URL 及导航；将归档资源替换为本地 Blob URL。

最终 HTML 置于无任何 allow 权限的 sandbox iframe 中；CSP 禁止脚本、外部请求、表单及对象。归档原始 JS 仅作为文件保留。切换收藏取消旧加载，撤销旧 Blob URL，防止旧请求覆盖新选择并释放资源。

## 主要 API

| 方法与路径                         | 权限             | 用途                    |
| ---------------------------------- | ---------------- | ----------------------- |
| GET `/health`                      | 受信来源         | 可用性检查，不返回令牌  |
| POST `/pair`                       | 受信来源＋配对码 | 申请浏览器令牌          |
| GET `/api/status`                  | 桌面/浏览器      | 连接和同步状态          |
| PUT `/api/blobs/:name`             | 桌面/浏览器      | 校验摘要并保存资源      |
| POST `/api/items`                  | 桌面/浏览器      | 新建收藏                |
| GET `/api/items?q=`                | 桌面             | 全文查询                |
| PUT/DELETE `/api/items/:id`        | 桌面             | 更新元数据/墓碑删除     |
| GET `/api/items/:id/content/:file` | 桌面             | 获取归档 HTML/JSON      |
| GET `/api/items/:id/assets/:name`  | 桌面             | 获取已归档资源          |
| GET/POST `/api/folders`            | 桌面             | 文件夹查询与创建        |
| PUT `/api/folders/:id`             | 桌面             | 重命名及调整父级        |
| GET/PUT `/api/settings`            | 桌面             | WebDAV 配置；不回传密码 |
| POST `/api/pairing`                | 桌面             | 重新生成短期配对码      |
| GET/DELETE `/api/devices[/token]`  | 桌面             | 查看与撤销浏览器配对    |
| POST `/api/sync`                   | 桌面             | 立即同步                |

## 平台视图与玻璃材质（0.2）

`app/library.js` 统一归类 X/twitter.com、Reddit 和普通网页，网页目录和计数始终排除社交帖子；网页文件直接嵌入对应目录的子节点，搜索保留祖先路径。`app/social.js` 分别渲染官网风格的书签／已保存信息流与详情，移除首页、探索、账号区与推荐栏；`app/media.js` 仅解析归档资源或内嵌图片，不加载远端图像。头像、图片、视频、作者、发布时间、社区和原始计数作为帖子元数据保存。

信息流打开帖子后显示同份归档中的回复/评论；原始快照仍经过既有 iframe 隔离。帖子文字先分词再转义，避免 URL/话题高亮破坏 HTML 实体或引入标签。

侧栏为低不透明度材质，页面底图可透过其模糊层。macOS 26 使用原生 Liquid Glass Clear，较旧 macOS 回退 Sidebar，Windows 使用 Mica/Acrylic；Tauri 窗口与 WebView 均设置为透明，右侧保持不透明；浏览器和 Linux 使用应用内场景作为背景。原生渲染仍需在目标操作系统验收。
