# Glassmark

**心に残るウェブを、手元に。**

[最新版をダウンロード](https://github.com/kevinhuang001/bookmark-web/releases/latest) · [English](README.md) · [简体中文](README.zh-CN.md)

記事、会話、ひらめきを保存して、自分のペースで読み返す。Glassmark はコンテンツとメディアを自分のパソコンに保管する、ローカル優先のウェブアーカイブです。

![Glassmark のウェブページ閲覧画面](docs/images/webpages.jpg)

## 保存したあとも、読みやすく

- **記事に集中**：ページ全体や複数の選択範囲を、レイアウトと一緒に保存。
- **なじみのある画面**：X のブックマーク、Reddit のコミュニティと階層コメント、小紅書の表紙一覧と左右分割の閲覧画面。
- **メディアも手元に**：画像、アバター、GIF、対応する動画をローカルに保管。
- **整理も検索も**：フォルダー、タグ、ライブラリ全体と保存元ごとの検索。
- **自分のサーバーで同期**：WebDAV を使ってデバイス間で同期。Glassmark アカウントは不要です。
- **多言語対応**：英語、簡体字中国語、日本語。保存した本文や自分で付けた名前は原文のままです。

![小紅書の保存一覧](docs/images/xiaohongshu.jpg)

## はじめる

1. [リリースページ](https://github.com/kevinhuang001/bookmark-web/releases/latest)から macOS、Windows、Linux 用アプリとブラウザー拡張機能をダウンロードします。
2. クライアントの「設定 → ブラウザー接続」でコードをコピーします。
3. 拡張機能にコードを貼り付け、ページや投稿の詳細を開いて保存します。
4. クライアントで読み返し、検索し、タグやフォルダーで整理します。

Chromium は拡張機能管理画面の開発者モードから解凍したフォルダーを読み込みます。Firefox は `about:debugging` から一時的に読み込み、再起動後は再度読み込む必要があります。保存中はクライアントを起動したままにしてください。

言語は「設定 → 一般 → 言語」で変更できます。拡張機能もクライアントの言語に従います。

保存対象はアクセス可能な読み込み済みコンテンツです。直接 MP4/WebM と暗号化されていない有限の HLS 動画に対応し、DRM やライブ配信の完全保存には対応していません。

スクリーンショットはサンプルコンテンツです。詳しい紹介は [English README](README.md) をご覧ください。
